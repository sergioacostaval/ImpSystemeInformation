# Stocks Investhink

## Présentation générale
Ce projet consiste à développer une application web simple pour analyser des actions (stocks) à partir de données historiques.

L’objectif principal est d’aider les débutants en trading à mieux comprendre les tendances du marché grâce à des indicateurs techniques simples et des signaux indicatifs.
